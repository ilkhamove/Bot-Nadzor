# Bot-Nadzor

MVP Telegram-бот для платформы технадзора по отделочным работам (штукатурка в Ташкенте).

## Возможности
- Клиент создаёт заявку через FSM-диалог и получает уведомления о смене статусов.
- Администратор видит последние заявки, открывает карточку и меняет статус с инлайн-кнопок.
- Статусы: NEW, SEARCHING, ASSIGNED, IN_WORK, INSPECT, DONE (с читаемыми названиями и цветами).
- SQLite-хранилище для заявок, инициализация таблиц при старте.

## Запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Установите переменную окружения `BOT_TOKEN` с токеном Telegram Bot API.
3. (Опционально) Инициализируйте БД отдельно:
   ```bash
   python -m nadzor_bot.init_db
   ```
4. Запустите бота:
   ```bash
   python -m nadzor_bot.bot
   ```

## Конфигурация
- Список администраторов задаётся в `nadzor_bot/bot.py` через множество `ADMINS`.
- База данных размещается в `nadzor_bot/data.db` (SQLite). Для перехода на PostgreSQL можно вынести слой DAL.

## Основные файлы
- `nadzor_bot/bot.py` — FSM, хендлеры, клавиатуры, уведомления.
- `nadzor_bot/db.py` — функции работы с SQLite (init, CRUD, обновление статусов).
- `nadzor_bot/init_db.py` — отдельный запуск инициализации БД.
- `requirements.txt` — зависимости.
